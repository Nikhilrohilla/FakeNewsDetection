This project is a Fake News Detection System built using Python and Machine Learning techniques.
The system analyzes news articles and predicts whether the news is real or fake using Natural Language Processing (NLP) and supervised learning algorithms.
The goal of this project is to combat misinformation by building an intelligent text classification model capable of identifying fake news based on textual patterns.
FEATURES:
	•	Data preprocessing and text cleaning
	•	Tokenization and stopword removal
	•	Feature extraction using TF-IDF / CountVectorizer
	•	Supervised machine learning model for classification
	•	Model evaluation with accuracy score
	•	Predicts whether input news is Real or Fake
TECHNOLOGIES USED:
	•	Python
	•	Pandas
	•	NumPy
	•	Scikit-learn
	•	Natural Language Processing (NLP)
